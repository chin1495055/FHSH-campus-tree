# 品牌視覺規範（草稿）

> 狀態：**草稿，等 Saori 與 Qmoa 討論確認**（2026/10/20）
> 作品名稱還沒定（候選見下方），名稱定了之後再補 Logo 方向。
> 神獸的個別設定在 [神獸角色設定.md](神獸角色設定.md)。

## 品牌個性

一句話：**像住在巷口、會記得你的大樹公。**

| 是 | 不是 |
|---|---|
| 溫暖、親切、有點俏皮 | 說教、悲情、恐嚇 |
| 台灣在地、有人情味 | 日系或歐美的通用風格 |
| 尊重民間信仰 | 拿宗教開玩笑 |
| 以事實為準、對事不對人 | 攻擊市府或特定人物 |
| 大人小孩都看得懂 | 只有工程師或專家懂的術語 |

## 作品名稱（候選）

還沒定案，推薦：

1. **契樹囝**：最在地、最有溫度，和神獸、認養的設定最搭。
2. **台北樹不起**：最有態度，適合當 slogan 或 Demo 結尾。
3. **Send Tree 培**：Qmoa 提議。台語「搧喙䫌」（siàn tshuì-phué，賞巴掌）的諧音，英文讀起來是「送一棵樹」，加上「培養」的培，三種語言一次到位。
   - **建議用法**：當求救卡或分享按鈕的名字（分享本來就是 Send 出去），或當票選期間的口號，例如「台北的樹被砍，就是在搧我們的喙䫌。Send Tree 培，送一棵樹回來。」
   - **當主名稱的風險**：活動由競選辦公室主辦，容易被解讀成「賞市府巴掌」，和「對事不對人」的原則衝突；也和神獸的溫暖調性不太搭，不會台語的人也聽不出梗。
   - 如果要當主名稱，Demo 和 README 要先講清楚正面的意思：「Send Tree（送樹）＋培（培養）」。

其他候選：樹你最大、顧樹、樹位守護、樹於你、樹不清、神樹出沒、守樹待護。

已排除：樹可夢（模仿寶可夢名稱，有商標疑慮）。

## 色彩

### 主要色

| 名稱 | 色碼 | 用途 | 由來 |
|---|---|---|---|
| 樹冠綠 | `#2F7D4F` | 主色：按鈕、重點、Logo | 老榕樹的深綠樹冠 |
| 深林綠 | `#1F4D33` | 標題、深色區塊 | 樹蔭底下的顏色 |
| 紅布紅 | `#C8382E` | 強調、求救、警示 | 大樹公身上綁的紅布 |
| 香火金 | `#E0A526` | 參拜、稀有、成就 | 廟裡的金色光 |
| 米紙白 | `#FAF6EE` | 頁面背景 | 宣紙、紅紙褪色後的暖白 |
| 墨色 | `#2B2A27` | 內文文字 | 書法的墨 |

### 樹木狀態色

| 狀態 | 色碼 | 圖示 |
|---|---|---|
| 正常 | `#3E9B5F` | 葉子 |
| 需關注 | `#E0A526` | 驚嘆號 |
| 公示中 | `#D9772B` | 公告牌 |
| 求救／即將移除 | `#C8382E` | 紅布、警鈴 |
| 保留／移植 | `#3A78C2` | 盾牌 |

**狀態不能只靠顏色表示**，一定要搭配圖示和文字（例如「公示中」三個字）。色弱的人分不出紅綠，戶外陽光下手機螢幕也看不清顏色。

### 注意

- 綠色是樹的顏色，但也接近政黨的代表色。整體視覺要靠紅布紅、香火金、米紙白建立自己的辨識度，不要做成一片綠。
- 最終色碼寫進程式前，要用對比檢查工具確認文字可讀（一般文字對比至少 4.5:1）。
- 要支援深色模式的話，由 Saori 決定是否在 MVP 範圍內。

## 插圖風格

### 原則

- **Q 版、圓潤**：2～3 頭身，線條粗而圓，沒有尖角。
- **平塗為主**：色塊乾淨，只加一點點陰影，縮小成地圖圖示也認得出來。
- **一眼看出是哪種樹**：每隻神獸都從真實樹種的特徵變形而來，例如榕樹的氣根變成鬍鬚。
- **加入台灣廟宇元素**：紅布、平安符、香火金光、燈籠，點到為止。
- **所有神獸同一套比例、線條粗細、配色規則**，看起來才像同一個世界。

### 避免

- **模仿現有 IP**：不要畫成寶可夢、皮克敏或其他現有角色的樣子。
- **恐怖或鬼怪感**：台灣也有「大榕樹下有鬼」的傳說，神獸要可愛，不要陰森。
- **畫出具體的神明**：不要畫成土地公、媽祖等真實神明的樣子，神獸是樹的化身，不是神明本人。
- **傷樹的畫面**：不要出現在樹上釘東西、用鐵絲纏繞、在樹根旁燒香燒金紙的畫面。

## 語氣與文案

- **台灣口語**：「這棵樹需要你」，不要寫成「該樹木需要您的關注」。
- **可以點綴台語**，但一句最多一個詞，而且要確認用法正確，例如「呷飽未？」「顧樹」。
- **對事不對人**：寫「這棵樹被公告要移除」，不要寫「市府又要砍樹了」。
- **模擬資料要說清楚**：「示範資料」「模擬情境」的標示要看得到，不要藏在小字裡。

### 文案範例

| 情境 | 這樣寫 | 不要這樣寫 |
|---|---|---|
| 首頁 | 你家附近有 12 棵樹，有 3 隻大樹神獸 | 歡迎使用樹木守護平台 |
| 守護成功 | 你成為鬚鬚公的第 129 位守護者 | 守護成功 |
| 需要關心 | 鬚鬚公最近沒什麼元氣，可以去看看它嗎？ | 警告：樹木健康異常 |
| 公示中 | 這棵樹被公告要移除，原因是公共工程。你可以…… | 市府又要砍樹了！ |
| 回報完成 | 謝謝你！這是市民觀察紀錄，不是專業診斷 | 診斷完成：疑似褐根病 |

## 製作方式

- **簡單的圖示**（地圖圖示、App 圖示）：可以請 Claude 畫成 SVG 向量圖，直接放進網頁。
- **神獸角色**：由 Claude 依角色設定寫繪圖提示詞，交給 AI 生圖工具（例如 Gemini）產圖，再挑選、修整。
- 用到的 AI 工具都要記在 README（比賽規則）。
- **什麼時候開始畫**：比賽規則寫「Day 1（10/23）起可開始討論與寫程式」，10/23 前能不能先畫圖要先問主辦單位。這份規範和角色設定是規劃文件，可以先寫。
