# 現場 Demo：電腦版 2 分鐘操作流程與口說稿

> 狀態：草稿（2026/10/24）。依部署版 https://2026-debugwithpuma.tree-god.workers.dev/ 實際操作過一次整理。
> 口說稿約 520 字，用平常說話的速度大約 2 分鐘。

## Demo 前準備（上台前 5 分鐘）

1. **開一個無痕視窗**打開網址，停在地圖首頁。無痕視窗沒有之前的守護紀錄，「守護祂」和燈數才會從頭開始。
   - 不用無痕的話：F12 → Console 輸入 `localStorage.clear()`，再重新整理。
2. 瀏覽器**全螢幕（F11）**，縮放 100%～110%，確認最後一排的人也看得到字。
3. 先在地圖上找到鬚鬚公（華山公園、橘色「公示中」那隻），確認點得到。
4. 手機開熱點當備案。網路完全不通的話，在 repo 跑 `python -m http.server 8000`，改用 http://localhost:8000/ 。
5. 「公示中・剩 10 天」是用今天日期算的，10/24 當天就是 10 天。

## 邊說邊操作

一列是一個動作：先做左邊的操作，邊做邊說右邊的話。操作欄是「無」就只講話。

| 時間 | 🖱 操作 | 🎤 要說的話 |
|---|---|---|
| **0:00** | 無（停在地圖首頁） | 如果你家門口的樹不見了，你多久會發現？ |
| | 無 | 東門的老茄苳被誤砍，美崙公園的紀念榕移除半年後才有人發現。不是沒人在乎，是消息到得太晚。 |
| | 滑鼠在地圖上繞一圈 | 這是「大樹神獸」。地圖上每一個點，都是臺北市開放資料裡真實的樹。 |
| **0:15** | 點華山公園的**鬚鬚公** → 右邊「**看祂的檔案**」 | 老樹在這裡是一隻神獸。這是華山公園的榕樹「鬚鬚公」，約 85 歲。 |
| | 按「**守護祂**」 | 住附近或常經過的人選「在地守護」，不住臺北也可以「遠端關注」。 |
| | 選「**在地守護**」，指一下左欄的燈海 | 按下去，燈海就多一盞燈：我是第 129 個守護祂的鄰居。只顯示人數，不公開是誰、住哪裡。 |
| **0:40** | 按「**回報樹況**」 | 守護者經過時花一分鐘回報。電腦版可以上傳在樹旁拍的照片，上傳前會移除位置資訊。今天先跳過照片。 |
| | 按「**先不放照片，直接檢查**」 | 檢查項目來自褐根病的早期徵兆和工程現場常見的問題：根有沒有隆起、樹幹有沒有網狀格紋、旁邊有沒有施工。 |
| | 勾**前四項**（樹根、樹幹、枝葉、樹穴），⚠️「樹旁沒有施工公告」**不勾** | 我看到樹旁貼了施工公告，所以這項不勾。 |
| | 按「**送出回報**」，指「待關注事項」 | 送出後，它變成「待關注」，正式上線會轉給管理單位，也通知其他守護者。政府巡視之間的空檔，就靠天天經過的鄰居補上。 |
| **1:10** | 上方導覽列按「**通知**」 | 如果這棵樹真的被公告要移除，守護祂的人會第一個知道：公示中，剩 10 天，還有說明會的時間地點。 |
| | 無 | 公告上寫清楚原因和管理單位，因為很多爭議其實來自分不清是誰的樹、為什麼要移。 |
| **1:30** | 按「**分享求援籤**」 | 一鍵產生求援籤，分享到 LINE、Threads。卡片上的 QR code 現在就可以掃，直接打開鬚鬚公的頁面，一起來當祂的鄰居。 |
| **1:45** | 無（停在求援籤畫面） | 新加坡讓每棵樹都有電子身分證；我們想讓臺灣每棵樹，都有一群守護祂的鄰居。 |
| | 無 | 樹的位置、樹種是真實開放資料，公告、回報和守護人數是模擬的。我們是 AI 方舟計畫，謝謝大家。 |

## 時間不夠時可以砍的地方

- **超時**：拿掉「通知」那一段，在神獸頁上方的「公示中：預計移除・10 天」橫幅帶過同一句話，直接按頁面裡的「分享求援籤」。
- **還有時間**：在神獸頁往下捲，帶到「社區佈告欄・本月 4 場活動」，講一句「守護一棵樹，也是在認識鄰居」。
