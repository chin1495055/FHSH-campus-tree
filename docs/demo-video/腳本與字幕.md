# Demo 影片：腳本、字幕與 Claude Design 提示詞

> 狀態：草稿（2026/10/23）。分鏡的理由與檢查清單見 [Demo影片企劃.md](Demo影片企劃.md)。
> 字幕檔：[Demo影片字幕.srt](Demo影片字幕.srt)，上傳 YouTube 時可以直接加進去，不用自己把字壓在影片上。

## 不用剪輯的做法

我們沒有人會剪片，所以整支影片設計成**一鏡到底錄下來就能上傳**：

1. **動畫段落**（背景、理念與願景、神獸登場、結尾）：交給 Claude Design 做成一個會自動播放的網頁，動畫部分約 40 秒。
2. **App 段落**：Day 2 程式定版後，用手機的「螢幕錄影」照固定路徑操作一次，約 60 秒。手機錄影不用剪，錄壞了就重錄。
3. **合在一起**：有兩個選擇，從簡單到更簡單：
   - **A. 兩段分開上傳**：YouTube 上傳兩支影片（介紹動畫＋App 實機操作），審核表填兩個連結。完全不用剪，但要先問主辦能不能交兩支。
   - **B. 一支影片**：把手機錄影檔放進 Claude Design 做的網頁，中間那段直接播手機錄影，然後用 Mac 的 QuickTime「新增螢幕錄製」把整個網頁從頭到尾錄成一支影片。也不用剪輯軟體。
4. **字幕**：上傳 YouTube 時加入 `Demo影片字幕.srt`。
5. **音樂**：先不放。沒有音樂比放錯音樂好；YouTube 上傳後可以從「音效庫」加免版稅音樂，不用剪輯軟體。

## 錄成影片的步驟（方式 B）

1. 把手機錄影檔改名成 `app-demo.mp4`，放進 Claude Design 網頁的同一個資料夾。
2. Mac 打開網頁，按 `F` 或瀏覽器全螢幕。
3. 打開 QuickTime Player → 檔案 → 新增螢幕錄製 → 選「錄製整個螢幕」→ 開始錄。
4. 回到網頁按空白鍵，等它播完，停止錄影。
5. QuickTime 會存成一個 .mov 檔，直接上傳 YouTube，加入字幕檔。
