## 回留言用的短句

| 情境 | 回覆 |

| 「這樣市府真的會聽嗎？」 | 我們想補的是「消息太晚」這一段：樹有異動時，在乎的人可以早點知道、早點表達意見。要接進市府流程需要哪些資源，寫在介紹頁的落地計畫裡。 |
| 「樹被砍都是市府的錯」 | 市府說明多數移除是病蟲害、自然死亡或颱風，我們相信也有很多是必要的。我們想解決的是誤砍和「太晚才知道」的狀況。 |
