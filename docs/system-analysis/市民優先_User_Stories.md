# 市民優先 User Stories

> 狀態：依 2026/10/19 的 MVP 草稿整理，供團隊討論與切分工作。
> 本稿採用常見敏捷 User Story 格式（身為／我想要／以便），並用 Given／When／Then 寫可驗收條件。

## 產品目標

讓市民容易找到並認識附近的樹、持續關心樹況，並在樹木異動時及早得知與參與。產品優先解決「樹不見了才發現」及「不知道為什麼、誰管理、去哪裡查」的資訊落差；市民回報補充現地觀察，不取代專業診斷或市府正式紀錄。

## 使用者角色

| 角色 | 需求與限制 |
|---|---|
| 在地守護者 | 住在附近或常經過，能到現場觀察、掃描樹木 QR code 並回報。 |
| 遠端關注者 | 不一定住在台北或樹木附近，可以追蹤樹木、接收異動資訊並分享。 |
| 親子同行者 | 由成人陪同認識樹木；兒童不需建立帳號，也不蒐集兒童個資。 |
| 市府／維護人員 | 非主要使用者；市府端查詢僅列為 P1 延伸，不影響市民主線。 |

## 優先級與範圍

- **P0：MVP 主線必須可操作**，涵蓋找樹、認識與守護、現場回報、異動提醒及分享。
- **P1：主線完成後再評估**，包含圖鑑、參拜大樹神獸、社區互動及市府端查詢。
- **P2：本次不實作**，保留為後續構想，不納入 MVP 驗收。
- P0 的通知、守護人數、狀態與回報資料可以使用模擬資料；介面與 README 必須清楚標示，不得讓人誤以為已連接市府系統。

## P0：MVP 主線

### Epic A：找到並認識附近的樹

#### US-01｜直接探索附近樹木

**身為**想認識住家或日常路線附近樹木的市民，
**我想要**打開手機就看到附近樹木地圖，
**以便**不用先註冊或知道樹號，也能開始探索。

**驗收條件**

- Given 我打開服務，When 首頁載入完成，Then 首頁顯示樹木地圖與可選取的樹木標記，不要求先登入。
- Given 裝置允許提供位置，When 地圖開啟，Then 地圖以目前位置附近作為初始範圍。
- Given 我拒絕位置權限，When 地圖開啟，Then 仍可瀏覽預設區域或手動移動地圖，不會被阻擋。
- Given 我目前的位置不在 MVP 樹木資料的範圍內，When 地圖開啟，Then 地圖改以預設地點為初始範圍，並提示「目前只收錄這個區域的樹」，不顯示一片空白。
- 預設地點：沈伯洋台北市長競選總部，臺北市中正區北平東路 30-1 號 1 樓（10/24 黑客松現場）。拒絕定位或不在資料範圍內時都使用此地點；地圖座標需在開發時查證。
- Given 地圖上有大型、高齡或受保護的樹，When 首頁載入，Then 這些樹以「大樹神獸」的專屬圖示標出，和一般樹木有明顯區別。
- Then 地圖上的真實樹木位置、樹種與樹號取自標示清楚的開放資料；模擬狀態不得混標為官方資料。

#### US-02｜查看單棵樹的身分與狀態

**身為**想確認一棵樹資訊的市民，
**我想要**查看樹種、樹號、管理單位、守護人數及目前狀態，
**以便**知道自己關心的是哪棵樹、由誰管理，以及是否有需要留意的異動。

**驗收條件**

- Given 我從地圖或分享連結開啟一棵樹，When 樹木頁載入，Then 頁面顯示可取得的樹木識別資訊、管理單位、狀態及守護人數。
- Given 某欄位沒有可靠資料，When 顯示樹木頁，Then 標示「資料未提供」或不顯示，不自行推測。
- Given 狀態或故事使用模擬資料，When 顯示該內容，Then 清楚標示為模擬資料。
- Then 「元氣」等遊戲化呈現不得被描述為專業健康診斷；市民觀察也不得被直接標成確診病害。

#### US-02a｜認識大樹神獸

**身為**想認識家附近老樹的市民，
**我想要**看到大型老樹化身為有名字、個性和來歷故事的「大樹神獸」，
**以便**把一棵樹當成有故事的鄰居來記住和關心，而不只是一筆樹木資料。

**驗收條件**

- Given 我開啟一棵被設定為神獸的樹，When 樹木頁載入，Then 頁面以神獸卡呈現，顯示神獸名字、個性、在地故事，以及真實的樹種、樹號和管理單位。
- Given 神獸卡顯示元氣值，When 這棵樹有新的市民回報，Then 元氣值依最近的回報變化；樹出現病徵或異動時，神獸呈現需要關心的狀態。
- Given 神獸的名字、個性與故事是團隊創作，When 顯示這些內容，Then 清楚標示為創作或模擬內容，和開放資料分開呈現。
- Then MVP 至少設定 3～5 棵神獸；其他樹木維持一般樹木頁即可。
- Then 神獸的設計要尊重台灣敬樹的民間信仰（如大樹公、樹王公），不做成搞笑或消費宗教的樣子。

### Epic B：加入守護並提供現地觀察

#### US-03｜選擇在地守護或遠端關注

**身為**想持續關心一棵樹的市民，
**我想要**選擇在地守護或遠端關注，
**以便**依照我能否到場，參與適合自己的守護方式。

**驗收條件**

- Given 我在樹木頁，When 我選擇守護，Then 可辨識地選擇「在地守護」或「遠端關注」。
- Given 我選擇遠端關注，When 完成操作，Then 我可以追蹤該樹並看到守護人數更新，不會被要求提供住址。
- Given 我選擇在地守護，When 完成操作，Then 頁面說明現場回報需在樹旁完成驗證。
- Then 公開頁只顯示守護人數，不公開守護者名單；Demo 使用的帳號與人數為模擬資料時須標示。

#### US-04｜掃描樹木 QR code 開啟正確頁面

**身為**已到樹旁的在地守護者，
**我想要**掃描樹上的 QR code 直接開啟該樹頁面，
**以便**確認樹木身分並開始現場回報。

**驗收條件**

- Given QR code 對應的樹木資料存在，When 我掃描 QR code，Then 系統開啟該樹的頁面，而不是要求我手動搜尋樹名。
- Given QR code 無法辨識或樹木資料不存在，When 掃描完成，Then 顯示可理解的錯誤與返回地圖的方式，不捏造樹木資料。
- Then MVP 可使用團隊製作的模擬 QR code；不得為驗證功能而自動抓取或掃描市府第三方系統。

#### US-05｜提交樹木現場觀察

**身為**在地守護者，
**我想要**拍照並勾選樹木健康或周邊施工觀察項目，
**以便**把定期巡查之間看到的變化留下紀錄。

**驗收條件**

- Given 我已進入在地回報流程，When 填寫回報，Then 可選擇根盤隆起、樹幹網狀格紋、枝葉稀疏、施工公告或樹穴遭填塞等觀察項目。
- Given 我選擇附照片，When 裝置提供相機或相簿權限，Then 可附上一張現場照片；拒絕權限時仍可提交文字或勾選觀察。
- Given 我尚未完成必要欄位，When 嘗試送出，Then 系統指出缺少欄位且保留已填內容。
- Given 回報送出成功，When 顯示完成結果，Then 顯示回報的樹木、觀察內容與時間，並清楚說明這是市民觀察、不是專業診斷。
- Then 回報流程只對在地守護者開放；Demo 可用掃描模擬 QR code 驗證，不保存住家地址或散步路線。

### Epic C：看見異動並邀請更多人關注

#### US-06｜查看樹木異動公告及其原因

**身為**關心一棵樹的市民，
**我想要**查看樹木是否有移除、移植或工程異動公告，以及原因與管理單位，
**以便**理解發生什麼事並找到後續查詢方向。

**驗收條件**

- Given 樹木有異動事件，When 我開啟樹木頁，Then 頁面顯示異動狀態、原因分類、管理單位及可取得的公告資訊。
- Given 原因或公告內容尚未取得，When 顯示事件，Then 清楚標示資料未提供或為模擬情境，不把推測寫成事實。
- Then 原因分類至少能表達病蟲害、天災／公安、公共工程及私人土地等類別；模擬事件需明顯標示。

#### US-07｜收到追蹤樹木的異動提醒

**身為**已追蹤樹木的市民，
**我想要**在樹木進入公示或異動狀態時收到提醒，
**以便**不必每天查看地圖，也能及早得知變化。

**驗收條件**

- Given 我已追蹤一棵樹且存在異動事件，When 我查看服務，Then 可在通知或樹木頁看到該事件與相關樹木連結。
- Given MVP 尚未串接推播服務，When 異動發生，Then 只以介面內的模擬通知呈現，並清楚標示為 Demo 模擬，不宣稱已發送手機推播。
- Then 通知開啟後可直接抵達對應樹木頁，並看到事件原因資料的來源或模擬標記。

#### US-08｜分享守護卡或異動求救卡

**身為**想邀請朋友一起關心樹木的市民，
**我想要**產生並分享樹木守護卡或異動求救卡，
**以便**讓朋友快速理解這棵樹的狀況並前往查看。

**驗收條件**

- Given 我在樹木頁，When 我選擇分享，Then 可產生含樹木名稱或樹號、守護人數、狀態及樹木頁連結的分享內容。
- Given 樹木有待關注的異動，When 我選擇求救卡，Then 分享內容清楚呈現異動狀態，且不加入未證實指控。
- Given 裝置不支援原生分享，When 我選擇分享，Then 可複製連結或使用可用的替代方式。
- Then 分享內容不得包含分享者位置、住家地址或散步路線；分享連結直接開啟對應樹木頁。

## P0 共通品質與信任條件

- **資料透明**：樹木位置、樹種與樹號可標示為開放資料；守護人數、回報、狀態、公示事件及通知如為模擬，需在頁面或資料說明中明確標示。
- **隱私最小化**：不要求住家地址；不公開守護者名單；定位只在必要時確認現場，不保存住家位置或個人散步路線。
- **不誤導**：市民回報是觀察資料，不等同市府認定、病害診斷或移除決定；遇到未確認資訊須明確標示。
- **手機可用**：主要流程可在手機完成；拒絕定位、相機或分享權限時，仍提供合理的替代操作。
- **可追溯**：樹木或事件資料來源可辨識；錯誤或缺漏不得以虛構的官方資料補齊。

## P1：主線完成後再評估

#### US-09｜收集樹種與老樹圖鑑

**身為**喜歡散步認識樹木的市民，
**我想要**查看已認識的樹種與特色老樹，
**以便**在探索城市時累積自然知識。

**驗收方向**：圖鑑資料能回到實際樹木頁；未收集項目可顯示剪影；大樹神獸是圖鑑裡的稀有款；樹種與故事的資料來源或模擬狀態清楚可辨。

#### US-09a｜參拜大樹神獸

**身為**認識了大樹神獸的市民，
**我想要**在神獸頁參拜、許願，並得到一則樹木小知識，
**以便**有理由常常回來看這棵樹，也用台灣人熟悉的敬樹方式表達關心。

**驗收方向**：神獸頁有「參拜」按鈕，搭配簡單的儀式動畫和一則樹木小知識；儀式感參考廟宇文化但保持尊重。介面不得鼓勵對樹木有害的實體行為（例如在樹幹釘東西、用鐵絲纏繞、在樹根旁燒香或燒金紙），可順便宣導正確的敬樹方式。不做抽卡或付費機制。

#### US-10｜參與同一棵樹的社區守護

**身為**想和鄰里一起守護樹木的市民，
**我想要**在樹木頁查看社區共同目標或匿名留言，
**以便**與其他關心同一棵樹的人互相提醒。

**驗收方向**：預設匿名、不公開守護者名單；共同目標以團體成果為主，不以個人排名施壓。留言管理與濫用處理規則需先定義再上線。

#### US-11｜讓維護人員查核樹木狀態

**身為**到場執行工作的維護人員，
**我想要**掃描樹木 QR code 並查看已核准的樹木狀態與異動資訊，
**以便**在作業前確認資訊一致並降低誤認風險。

**驗收方向**：此為市府／維護端延伸，不屬於市民 P0；畫面只能依正式授權與核實資料提供作業判斷，不以模擬資料作為真實施工指令。

#### US-12｜切換到市民最常提到的區域

**身為**想看看其他地方樹況的市民，
**我想要**一鍵切換到市民最常提到的區域，
**以便**不用自己拖地圖找，也能看到大家關心的地方。

**驗收方向**：除了預設地點，再收錄美崙公園、民生社區、敦化南路周邊的樹（「市長，你給我聽好了」種樹留言中最常被點名的地點，各 41、40、37 則，見種樹痛點儀表板）。地圖上有「切換區域」按鈕，點了跳到該區域並顯示收錄的樹。

## P2：不納入本次 MVP

- 親子陪伴與兒童友善探索（不建立兒童帳號、不蒐集兒童個資）。
- 個人散步路線綠化、拍照長出樹等遊戲機制。
- 社區活動、跨世代樹木故事採集、全台縣市擴充。
- 樹蔭供需與增綠缺口分析；未取得可靠資料與明確方法前，不呈現成官方公平評分。
- 真正的推播、正式帳號系統，以及串接市府內部巡查、施工或移除資料。

## 需求依據與限制

- [專案背景與產品方向](../../CLAUDE.md)：市民主體、在地與遠端守護、隱私原則及比賽限制。

- [近期移樹爭議整理](../../data/research/背景事件整理.md)：事件與市府說明仍須回到原始來源查證，不能把整理內容直接當作已驗證事實。
- [開放資料清單](../../data/research/openDataList.md)：樹木基礎資料可參考公開資料；移除原因、守護與市民回報等資料目前以模擬資料為主。
