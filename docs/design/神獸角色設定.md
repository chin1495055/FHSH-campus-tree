# 大樹神獸角色設定（草稿）

> 狀態：**草稿，等 Saori 與 Qmoa 討論確認**（2026/10/20）
> 畫風、配色、語氣規則見 [品牌視覺規範.md](品牌視覺規範.md)。
> 神獸的名字、個性、故事都是**團隊創作**，介面上要標示為創作內容，和開放資料分開。

## 設定原則

1. **每隻神獸對應一種台北常見的真實樹種**：造型從樹的真實特徵變形，認識神獸也等於認識樹。
2. **樹種知識要正確**：小知識寫進作品前要查證。
3. **不拿真實的紀念樹或爭議樹當神獸**：例如美崙公園被移除的紀念榕、東門被誤砍的茄苳。真實事件只放在 Demo 開頭和 README 講，神獸用虛構的個體，避免消費真實事件。
4. **地點從開放資料挑**：MVP 的神獸要對應資料裡真實存在的樹（位置、樹種、樹號是真的，名字和故事是創作的）。至少一隻要在 Demo 現場（競選總部，中正區北平東路 30-1 號）附近。
5. **元氣跟著真實狀況走**：神獸的狀態由市民回報和異動事件決定，不是隨機的遊戲數值。

## 共通的狀態表情

每隻神獸都要畫這幾種狀態：

| 狀態 | 什麼時候出現 | 表情與造型 | 優先 |
|---|---|---|---|
| 元氣滿滿 | 最近的回報都正常 | 笑臉、葉子飽滿、身上有淡淡金光 | P0 |
| 需要關心 | 回報出現病徵（根盤隆起、枝葉稀疏等），或很久沒人回報 | 眼睛下垂、葉子掉幾片、冒汗 | P0 |
| 求救 | 被公告要移除，或回報有施工、樹穴被填 | 舉著紅布做的求救旗，表情緊張但不恐怖 | P0 |
| 被參拜 | 有人參拜時 | 閉眼微笑、金光變亮 | P1 |

## 神獸名單

MVP 至少做 3 隻（★ 標示），時間夠再做到 5 隻。

### ★ 1. 鬚鬚公（榕樹）

- **樹種**：榕樹（*Ficus microcarpa*）
- **稀有度**：傳說（圖鑑最稀有）
- **真實特徵 → 造型**：
  - 從枝幹垂下的氣根 → 長長的白鬍鬚
  - 樹冠又大又圓 → 圓滾滾的大頭，像戴了一頂綠帽子
  - 身上綁著紅布 → 大樹公的象徵
- **個性**：慢條斯理、愛講古，記得整條街幾十年來發生的事。長輩們最喜歡在它底下下棋聊天。
- **口頭禪**：「慢慢來，樹仔是一年一年大的。」
- **在地故事（創作）**：社區還是一片稻田的時候它就在這裡了。附近的孩子都給它做過契子，每年有人來向它報告考試成績。
- **小知識**：榕樹的氣根垂到地面後會變粗，變成支撐的「柱子」，所以一棵老榕樹可能看起來像一片小樹林。
- **為什麼要守護**：榕樹是褐根病常見的受害者之一。根盤隆起、樹幹出現網狀紋路、枝葉變稀疏，都可能是警訊，越早發現越有機會處理。
- **Demo 角色**：Demo 的主角神獸，演「被公告移除 → 守護者發聲」的情境。

### ★ 2. 加冬仔（茄苳）

- **樹種**：茄苳（*Bischofia javanica*），台語叫「加冬」
- **稀有度**：稀有
- **真實特徵 → 造型**：
  - 一片葉子由三片小葉組成（三出複葉）→ 頭上頂著三片葉子，像三根呆毛
  - 樹皮紅褐色、會片狀剝落 → 紅褐色的皮膚，有可愛的斑紋
  - 秋冬結出成串的小果子 → 背著一串圓圓的果實當背包
- **個性**：熱心、愛照顧人，是社區的大姊頭。看到有人經過就想招呼對方吃飯。
- **口頭禪**：「呷飽未？」
- **在地故事（創作）**：以前的人說茄苳很「好養」，老一輩會用茄苳葉燉雞。它最喜歡聽大家講家裡的事。
- **小知識**：茄苳是台灣原生樹種，台灣有不少老地名跟它有關（例如「茄苳腳」，實際的地名和位置寫進作品前要查證）。
- **建議位置**：Demo 現場附近（中正區），讓大家當天就能去掃 QR code。

### ★ 3. 雀雀（雀榕）

- **樹種**：雀榕（*Ficus subpisocarpa*）
- **稀有度**：稀有
- **真實特徵 → 造型**：
  - 果實長在枝幹上、鳥最愛吃 → 頭上、肩上總是停著好幾隻小鳥
  - 一年會落葉、換新葉好幾次，新芽是粉紅色的 → 常常換「髮型」，新芽時頭上冒出粉紅色的嫩葉
- **個性**：熱鬧、好客、交遊廣闊，是社區的交際花。最喜歡介紹守護者互相認識。
- **口頭禪**：「來來來，我介紹朋友給你認識！」
- **在地故事（創作）**：附近的白頭翁、綠繡眼都是它的老朋友，每到結果的季節，樹上熱鬧得像夜市。
- **小知識**：雀榕的種子被鳥吃下後，常常在別的樹或牆縫裡發芽，所以有時候會在奇怪的地方看到雀榕長出來。
- **和社區連結的關係**：雀雀可以當「樹友」功能的代言神獸。

### 4. 樟腦伯（樟樹）

- **樹種**：樟樹（*Cinnamomum camphora*）
- **稀有度**：普通
- **真實特徵 → 造型**：
  - 葉子揉碎有樟腦的香味 → 身邊飄著淡淡的香氣線條
  - 樹皮有直直的深溝紋 → 穿著有直條紋的外套
- **個性**：有點驕傲、愛乾淨，自稱是「台灣以前最有名的樹」。
- **口頭禪**：「想當年，全世界都知道我們台灣的樟腦。」
- **小知識**：台灣以前是全世界重要的樟腦產地，樟腦曾經是很重要的出口品。（數字和年代寫進作品前要查證。）

### 5. 欒四季（臺灣欒樹）

- **樹種**：臺灣欒樹（*Koelreuteria elegans* subsp. *formosana*）
- **稀有度**：普通
- **真實特徵 → 造型**：
  - 一年會變好幾種顏色：綠葉、黃花、紅褐色的果實 → 會隨季節換裝，圖鑑裡可以收集它的四季造型
  - 果實像一個個小燈籠 → 手上提著紅色小燈籠
- **個性**：愛打扮、愛拍照，每一季都要換新造型。
- **口頭禪**：「你看我今天這套怎麼樣？」
- **小知識**：臺灣欒樹是台灣特有種，台北很多行道樹都是它，秋天整條路會變成黃色和紅褐色。
- **和圖鑑的關係**：可以當「同一棵樹不同季節造型」的收集玩法示範（P2，先不做）。

## 參拜祝福語（P1）

參拜後隨機出現一則，內容是祝福加上樹木小知識：

- 鬚鬚公：「保庇你今年平平安安。順帶一提，我的鬍鬚其實是氣根喔！」
- 加冬仔：「保庇你呷百二。我的葉子是三片一組的，下次看看！」
- 雀雀：「保庇你交到好朋友。今天有幾隻鳥來找我玩，你數得出來嗎？」

台語用詞寫進作品前要找會講台語的人確認。

## 給 AI 生圖的提示詞方向

每隻神獸產圖時，共通的描述放前面，再加上個別的特徵。以下是方向，實際提示詞到時再依工具調整：

> 共通：3D 渲染的 Q 版吉祥物，2～3 頭身，圓滾滾的造型，軟膠公仔質感、霧面表面，左上方柔和打光，正面稍微俯視的鏡頭，米白色純色背景，台灣廟宇元素點綴（紅布、金光），可愛溫暖，不恐怖，不模仿任何現有卡通或遊戲角色。
>
> 鬚鬚公：以榕樹為原型的老爺爺神獸，白色氣根變成長鬍鬚，圓滾滾的綠色樹冠大頭，身上綁一條紅布，笑瞇瞇。

- 先產 1 隻確認畫風，再用同一套描述產其他隻，畫風才會一致。
- 純色背景比較好去背，去背後才能放進地圖圖示和分享卡。
- 鬚鬚公是 Demo 主角，會另外做成可轉動的 3D 模型（P1）。如果用 AI 轉 3D 工具，要丟一張正面、全身、沒有被遮住的圖，轉出來比較完整。
- 產好的圖要檢查有沒有像現有的卡通角色，有的話就重產。
- 用了哪個工具、哪些圖是 AI 產的，都要寫進 README。
- **實際產圖紀錄（10/20）**：鬚鬚公、加冬仔、雀雀的「元氣滿滿」和「需要關心」共 6 張，由 Qmoa 用 **ChatGPT** 產生，去背和壓縮由 Claude 處理。檔案在 `assets/beasts/`（還沒 commit，等主辦單位確認 10/23 前能否先做素材）。
