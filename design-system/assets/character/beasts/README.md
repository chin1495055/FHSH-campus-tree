> `xuxugong/healthy.png` 和 `../xuxugong-3d.png` 是同一張圖。神獸名字統一用角色設定的版本：鬚鬚公、加冬仔、雀雀（10/22 Qmoa 決定）。

## 檔案

每隻都有「healthy（元氣滿滿）」和「sad（需要關心）」兩種狀態，各三種版本：

| 檔名 | 尺寸 | 用途 |
|---|---|---|
| `{狀態}.webp` | 640×800，米白底 | App 內的神獸頁、分享卡 |
| `{狀態}-cutout.webp` | 寬約 530 × 高 800，透明底 | 疊在其他背景上 |
| `{狀態}-icon.webp` | 96×96 | 地圖標記、圖鑑卡小圖。`healthy-icon` 是臉部特寫（10/22 更新），`sad-icon` 還是全身縮圖 |
| `{狀態}.png`、`{狀態}-cutout.png` | 原始大圖，約 1.5～2 MB | 簡報、影片、印刷用，**不要直接放進 App** |

App 裡一律用 `.webp`，手機載入才快。
