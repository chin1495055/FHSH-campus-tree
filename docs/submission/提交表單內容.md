## 作品簡介（300 字內）

```
用遊戲的方式守護家附近的樹。市民可以守護一棵樹、回報樹況，老樹會化身「大樹神獸」。樹要被移除前，所有守護者都會收到異動警報，看得到原因分類、管理單位和意見截止日，也能分享「這棵樹需要你」號召更多人，誤砍就不容易發生。新加坡讓每棵樹有身分證，我們讓每棵樹有一群鄰居。地圖樹木為真實開放資料，守護人數與公示為模擬資料。
```

## 未來需要哪些資源（1000 字內，不公開）

```
【試辦範圍】中正區，約 9,100 棵樹，100 天。原則是接上市府現有的樹木 ID、QR code、定期巡視與小樹保衛站，不另起爐灶。

【局處】
1. 公園處：主責。提供樹木狀態與異動排程，在後台回覆市民回報，並把移除與移植公示同步到平台。
2. 文化局：提供受保護樹木名單，異動時提高警示等級。
3. 資訊局：資安與個資審查、既有系統串接、台北通登入。
4. 中正區公所與各里：里長發起巡樹活動。
5. 教育局：試辦後期與國小合作親子圖鑑。

【資料】樹木分布圖（已開放）；QR code ID 與開放資料編號是否同一套（待查證）；樹木狀態、公示與原因分類（需公園處提供）；最後巡視日期；受保護樹木名單。

【時程】
第 0～30 天：跨局處窗口、ID 比對、平台加上後端與登入、資安審查。
第 31～60 天：3～5 個里試辦，移除前公示通知守護者。
第 61～100 天：擴大全區，辦巡樹日，公開成果報告。

【經費估算】合計約 200～435 萬元。平台正式化 150～300 萬，雲端 5～10 萬，QR 樹牌 0～50 萬，社區推廣 30～60 萬，回應回報人力約 15 萬。

【推廣】在樹牌旁貼「掃我，認識這棵樹」，由里長帶頭，與國小合作，用分享卡社群擴散。
```
